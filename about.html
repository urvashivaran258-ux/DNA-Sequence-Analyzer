About Project

DNA Sequence Analyzer is a Bioinformatics mini project developed using HTML, CSS and JavaScript.

This website analyzes DNA sequences and calculates:

  • Total DNA Length
  • Adenine (A)
  • Thymine (T)
  • Guanine (G)
  • Cytosine (C)
  • AT Content (%)
  • GC Content (%)
