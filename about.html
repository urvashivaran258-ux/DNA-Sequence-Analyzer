About Project

DNA Sequence Analyzer is a Bioinformatics mini project developed using HTML, CSS and JavaScript.

The main purpose of this project is to analyze a DNA sequence and calculate its nucleotide composition.

What Does It Calculate?

  • Total DNA Length
  • Adenine (A) Count
  • Thymine (T) Count
  • Guanine (G) Count
  • Cytosine (C) Count
  • AT Content (%)
  • GC Content (%)
